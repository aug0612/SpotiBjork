# SpotiBjork 🎵

Spotify web wrapper with Material You and Apple Music aesthetics.

## Features
- Material You & Liquid Glass
- Apple Music-inspired UI
- Ad-free Experience
- Background Playback

## Build
```bash
./gradlew assembleDebug
```
