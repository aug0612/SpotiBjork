# SpotiBjork 🎵

Spotify web wrapper with Material You and Apple Music aesthetics.
Uses Spotify Web Player PC version for full desktop experience.

## Features
- Material You & Liquid Glass
- Apple Music-inspired UI
- Spotify Web Player PC Version
- Ad-free Experience
- Background Playback

## Build
```bash
./gradlew assembleDebug
```
